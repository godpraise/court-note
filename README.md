# 코트노트 (Court Note)

피클볼 코치의 예약·회원·레슨 기록·수강권·정산을 한곳에서 관리하는 PWA 웹앱입니다.

JavaScript·Firebase·Vercel·Anthropic API를 사용했습니다. 초기 공유형 앱은 2026년 8~9월에 개발·배포했습니다. 이 저장소에는 이후 로컬에서 개선한 코치별 데이터 분리와 수업 완료 트랜잭션도 포함합니다. **후속 개선은 운영 서비스에 미배포 상태입니다.**

## 맡은 역할과 AI 활용

지인의 아이디어를 수업 전후 업무 흐름과 화면·기능·예외 조건으로 구체화했습니다. 코드는 AI 도구로 생성·수정했고, 오류 상황을 설명해 수정을 요청한 뒤 실행 결과를 확인했습니다. 전체 코드를 직접 독립 작성한 프로젝트로 설명하지 않습니다.

## 주요 코드

| 파일 | 내용 |
| --- | --- |
| `index.html` | 예약·회원·레슨·수강권·정산 화면과 Firestore 연동 |
| `coach-session.js` | 로그인 UID별 경로, 구독 해제와 계정 전환 상태 관리 |
| `lesson-completion.js` | 레슨 완료와 수강권 차감을 함께 저장하는 트랜잭션 |
| `api/clean-note.js` | 토큰·인증 이메일·등록 코치·입력 검증 후 AI 메모 요청 |
| `firestore.rules` | 등록된 코치의 본인 데이터만 허용 |
| `manifest.json`, `sw.js`, `icons/` | PWA 설치·캐시 구성 |
| `tests/` | 세션·API·접근 권한·완료 처리 로컬 테스트 |

이메일 링크 로그인 후 `coaches/{uid}/{collection}/{document}`에 업무 자료를 저장합니다. 다른 코치의 데이터와 기존 공통 테스트 자료 접근은 규칙으로 차단합니다. 새 코치 계정은 빈 상태로 시작하며 기존 자료를 자동 삭제·이전하지 않습니다.

## 문제와 후속 개선

같은 레슨을 반복 완료하면 수강권이 다시 차감되는 문제를 확인했습니다. AI 도구로 최신 레슨·수강권을 읽은 뒤 완료 상태와 차감을 하나의 트랜잭션으로 저장하도록 보완했습니다. 이미 완료한 레슨은 다시 차감하지 않으며, 수강권 누락·소진 등 오류 시 전체 저장을 중단합니다.

- [코치별 데이터 분리](docs/coach-isolation.md)
- [중복·동시 완료 처리와 테스트](docs/lesson-completion.md)

## 실행과 로컬 테스트

테스트에는 Node.js 22 이상과 Java 21 이상을 권장합니다.

```sh
npm ci
npm test
npm run test:rules
```

`demo-court-note-isolation`과 로컬 Firestore 에뮬레이터를 사용합니다. 운영 데이터나 Anthropic API를 호출하지 않습니다.

| 검증 범위 | 테스트 수 |
| --- | ---: |
| 세션·API 인증·입력 | 11 |
| 코치별 데이터 접근 규칙 | 7 |
| 중복·동시 요청·롤백 등 완료 트랜잭션 | 10 |
| 합계 | 28 |

[2026-11-20 재검증](docs/verification-2026-11-20.md)에서 28개 모두 통과했습니다.

별도 환경에서 앱을 실행하려면 자신의 Firebase 프로젝트·이메일 링크 로그인·등록 코치 목록을 설정해야 합니다. 클라이언트 설정 예시는 `examples/firebase-config.example.js`, 서버 변수 이름은 `.env.example`을 참고합니다. 실제 키·서비스 계정 JSON은 Git에 넣지 않습니다.

정적 화면과 `/api/clean-note`를 함께 제공해야 하며, 정적 서버만으로 AI 메모 API까지 실행되지는 않습니다. 현재 진입점은 루트 `index.html`입니다. `examples/index.template.html`은 과거 공유형 보존 예시입니다.

## 확인한 결과와 남은 검증

피클볼 코치들과 친분이 있는 협회 관련 지인에게 초기 긍정 반응을 확인했습니다. 이후 지인이 별도로 제작하겠다는 의사를 밝혀 구체적인 후속 피드백은 받지 못했습니다. 실제 코치의 업무 사용 기록, 시간 절감·오류 감소·장기 이용 지표는 없습니다.

회원 출석을 코치에게 알리는 자동화는 당시 아이디어이며 구현·검증한 기능에 포함하지 않습니다. 완료 후 편집·취소의 역정산, 과거 잘못된 데이터 복구, 실제 로그인·기기 간 캐시·운영 안정성은 추가 검증 대상입니다. 로컬 테스트 28건은 실제 이용자 수나 업무 성과를 뜻하지 않습니다.

## 저장소 공개와 배포

2026-11-20에 후속 개선 코드와 설명을 GitHub에 반영합니다. 운영 배포를 보류하고 있어 `vercel.json`에서 Git 자동 배포를 껐습니다. 향후 배포할 때는 코드·서버 함수·Firebase 규칙을 함께 검토해야 합니다. [Vercel 자동 배포 설정](https://vercel.com/docs/project-configuration/git-configuration#turning-off-all-automatic-deployments)

원본·기존 Git 이력은 보존합니다. 새 오픈소스 라이선스를 임의로 부여하지 않았습니다.
