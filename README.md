# 코트노트 (Court Note)

피클볼 코치의 예약·회원·레슨 기록·수강권·정산을 연결하는 PWA 웹앱입니다.

## 작업 범위

- 개발 기간: 2026.08~2026.09 (기존 이력서와 사용자 회고 기준)
- 지인의 아이디어를 바탕으로 상세 기획·설계, AI 활용 구현, 예외 검토·수정과 배포를 수행했습니다.
- 코치 개인 업무를 먼저 연결하고, 다중 코치 서비스는 후속 과제로 구분했습니다.

## 기술과 파일

- `index.html`: Vanilla JavaScript 화면과 업무 상태 처리, Firestore 연동
- `api/clean-note.js`: Firebase ID 토큰과 입력을 확인한 뒤 Anthropic API에 메모 정리를 요청하는 Vercel 서버 함수
- `firestore.rules`: 보존된 Firestore 규칙
- `manifest.json`, `sw.js`, `icons/`: PWA 구성

AI 요청 키와 서비스 계정 정보는 서버 환경변수로 관리합니다. 토큰 유효성 검증과 코치별 데이터 접근 권한은 별개입니다.

## 실행 준비

1. `npm install`로 `package.json`에 명시된 서버 의존성을 설치합니다. 원본에 lock 파일과 실행 스크립트는 없었습니다.
2. `index.html`의 Firebase 설정이 사용할 프로젝트와 맞는지 확인합니다. 별도 프로젝트용 설정 예시는 `examples/index.template.html`의 `YOUR_FIREBASE_*` 값을 참고합니다.
3. `.env.example`의 변수 이름을 참고해 자신의 서버 환경변수를 설정합니다. 실제 `.env`나 서비스 계정 JSON은 Git에 추가하지 않습니다.
4. 정적 화면과 `/api/clean-note` 서버 경로를 함께 제공하는 환경이 필요합니다. 단순 파일 열기나 정적 HTTP 서버만으로 AI API까지 실행되지는 않습니다. 배포는 자신의 Vercel/Firebase 설정을 별도로 확인한 뒤 진행합니다.

## 현재 결과와 한계

예약·기록·정산을 연결한 앱을 구현·배포했고, 지인·동생의 긍정적 시연 반응이 있었다는 사용자 회고가 있습니다. 실제 코치 업무 시간·매출·장기 사용 지표는 없습니다. 1분 확인·3분 저장은 기획 목표이며 측정 성과가 아닙니다.

2026-11-12 함수 단위 모의 환경에서 같은 레슨을 다시 완료하면 수강권 사용 횟수가 1에서 2로 증가하는 동작이 확인됐습니다. **이 문제는 해결한 성과가 아니라 미해결 개선 과제입니다.** 다중 코치 격리, 중복·동시 요청, 실제 운영 권한과 AI 응답 품질은 추가 검증이 필요합니다.

기존 `court-note` 저장소의 실행 파일은 유지하고, 별도 포트폴리오 저장소의 README·환경변수 예시를 통합했습니다. 설정값을 익명화한 화면 버전은 `examples/index.template.html`에 보존했습니다. 기능 수정이나 직접 서비스 배포를 수행한 것은 아닙니다. 원본·서비스 계정·기존 저장소 이력은 별도로 보존했습니다. 새 라이선스를 임의로 추가하지 않았습니다.
